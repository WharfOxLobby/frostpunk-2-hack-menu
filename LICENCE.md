## 🧩 About

**Frostpunk 2 Companion** is a curated list of Frostpunk 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource viewer, time control notes
- **Quality-of-Life Helpers** — building catalog, citizen manager, overlay notes
- **Research Notes** — city layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Resource Overlay — track key resources at a glance
- Time Control Notes — pause and speed adjustment for study
- Build Planner — preview construction layouts
- Citizen Monitor — population and needs overview

### 🏗️ City Management
- Building Catalog — browse structures and requirements
- Policy Notes — organize law and research paths
- Heat Map Overlay — visualize warmth distribution

### 📊 Strategy Layout
- Scenario Notes — plan progression for each scenario
- Event Tracker — log key decisions and outcomes
- Save Manager — backup and restore city states
